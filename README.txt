DOMPETKU PWA
============
Isi folder: index.html, manifest.webmanifest, sw.js, icons/

CARA PASANG (GitHub Pages, gratis)
1. Buat repository baru di GitHub, upload SEMUA isi folder ini ke root repository.
2. Settings > Pages > Source: "Deploy from a branch" > branch main, folder / (root) > Save.
3. Tunggu 1-2 menit, buka https://USERNAME.github.io/NAMA-REPO/ di Chrome HP.
4. Menu Chrome (titik tiga) > "Instal aplikasi" / "Tambahkan ke layar utama".
(iPhone: buka di Safari > Bagikan > "Tambah ke Layar Utama".)

ALTERNATIF: Netlify Drop (app.netlify.com/drop) - seret folder ini, selesai.

MEMINDAHKAN DATA LAMA
Di aplikasi lama: Pengaturan > Export. Di aplikasi baru: Pengaturan > Import.

MEMPERBARUI APLIKASI
Ganti index.html, lalu naikkan VERSION di sw.js (mis. 'v1' -> 'v2') agar cache HP ikut diperbarui.
